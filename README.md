# PARCELA

Partitioning and Allocation of Real-Property using Computational Engine for Land Analysis

PARCELA is a web-based academic project developed as part of our
Bachelor of Science in Computer Engineering program at Eastern Samar
State University.

The system explores the use of computational and geospatial techniques
for land partitioning and allocation. It provides an interactive
web-based interface for working with land boundaries and generating
partition layouts.

## Key Features

- Land partitioning and allocation
- Interactive map visualization
- Geospatial processing and calculations
- Support for land boundary data
- Automated layout generation
- Project data management
- PDF report generation

## Technologies Used

- React – User interface development
- TypeScript – Application programming and type safety
- Vite – Development and build tool
- Tailwind CSS – User interface styling
- Supabase – Backend and database services
- Leaflet / React Leaflet – Interactive map visualization
- Turf.js – Geospatial calculations and processing
- jsPDF – PDF report generation
- html2canvas – Capturing interface elements for generated reports
- Git & GitHub – Version control and project repository
